# Desktop Automation Research Corpus

This folder is Yomi's local-only R&D corpus for desktop automation research.

It is intentionally ignored by git and must never be packaged, deployed, or committed.

## Contents

- `research_index.json` — searchable source/concept index.
- `research_gap_report.md` — current Yomi capability gaps vs corpus patterns.
- `feature_adoption_scoring.md` — scoring rules before implementation.
- `continuous_improvement.md` — recurring R&D workflow.
- Source folders for UIA, FlaUI, Playwright, OpenCV, PaddleOCR, Browser Use, Open Interpreter, Hermes, LangGraph, Win32, and Accessibility Insights.

## Rule

Extract concepts, patterns, tests, and architecture. Do not copy external code into Yomi.
